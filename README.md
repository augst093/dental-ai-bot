# 🦷 DentaLux Tashkent — Премиальный B2B AI-Ассистент и Движок Напоминаний

Интеллектуальный Telegram-бот на базе **Python 3.11+**, **aiogram 3.x** и **DeepSeek API (`deepseek-chat`)** с поддержкой **Function Calling**, постоянным воркером напоминаний и строгими медицинскими guardrails для клиник Ташкента.

---

## 🎯 Бизнес-задачи и ценность

- **Высокий чек ниши:** Пациенты на брекеты, элайнеры, виниры и имплантацию приносят клинике от **$500 до $3,000+**.
- **Борьба с неявками (No-Show Engine):** Автоматические напоминания за 24 часа и за 2 часа с кнопками подтверждения в 1 клик сокращают неявки на 35–45%.
- **Окупаемость рекламы:** При затратах на таргет в Instagram/Facebook от $1,000 до $4,000 в месяц бот исключает потерю лидов.
- **Работа 24/7 без потерь:** Более **40% заявок** приходят вечером, ночью и в выходные. Бот отвечает за 2-3 секунды, квалифицирует интерес и забирает контакт.
- **Двуязычие (UZ/RU):** Безупречное и естественное общение на русском и узбекском языках (латиница и кириллица) с автоматическим распознаванием с первого сообщения.
- **Медицинская безопасность:** Защита от медицинских галлюцинаций — бот строго не назначает лекарства и дозировки, а при острой боли проводит триаж и соединяет с регистратурой.
- **Защита персональных данных:** PII-маскирование перед отправкой в LLM (номера телефонов заменяются на `[ТЕЛЕФОН_СКРЫТ]`, Telegram ID не передаются в AI-провайдер), поддержка команды `/delete_my_data`.

## ⚡️ Ключевой функционал

### 1. Фоновый воркер напоминаний (`reminder_service.py`)
- Запускается параллельно с ботом (`asyncio.create_task`) и проверяет базу каждую минуту.
- Отправляет напоминание за **24 часа** и за **2 часа** до назначенного времени приёма (в часовом поясе `Asia/Tashkent`).
- Интерактивные инлайн-кнопки:
  - `✅ Да, приду` — переводит запись в статус `confirmed`, обновляет карточку сообщения.
  - `🔄 Перенести` — переводит в статус `reschedule_requested` и немедленно уведомляет администратора для согласования нового времени.
  - `❌ Отменить` — переводит в статус `cancelled`, мгновенно освобождает слот для других пациентов в Mini App и отправляет алерт в админ-чат.
- **Устойчивость к сбоям:** Если пациент заблокировал бота, перехватывается `TelegramForbiddenError`, напоминание помечается как `failed`, а администратору отправляется сообщение: *«Пациент заблокировал бота — позвоните ему лично»*.

### 2. Медицинские Guardrails и Триаж Острой Боли
- **Строгий отказ от назначения лекарств:** При любых вопросах о дозировках антибиотиков или обезболивающих бот объясняет, что препараты подбираются только очно с учетом аллергоанамнеза, и предлагает экстренную запись.
- **Триаж экстренных состояний:** При симптомах острой пульсирующей боли, отека щеки (флюс), травмы зуба или кровотечения бот определяет экстренность, выдает правила первой помощи (не греть, приложить холод) и предлагает немедленный звонок в клинику.

### 3. Конфиденциальность и Закон о персональных данных
- **PII Stripping:** Регулярные выражения в `ai_service.py` маскируют телефонные номера (`[ТЕЛЕФОН_СКРЫТ]`), из контекста исключаются реальные имена и Telegram ID. Сторонний LLM-сервер получает только обезличенный медицинский запрос.
- **Команда `/delete_my_data`:** Пациент может в любой момент удалить историю переписки и анонимизировать свои данные в базе клиники.

### 4. Дайджест для владельца клиники (`/digest`)
- Команда администратора `/digest` рассчитывает реальную конверсию за последние 7 дней:
  - Всего записей
  - Подтвержденных визитов
  - Долю неявок (No-show)
  - Спасенных слотов
  - Сэкономленные часы администратора

## 🚀 Настройка и запуск

### 1. Настройка окружения:
Скопируйте пример файла:
```bash
cp .env.example .env
```
Заполните обязательные переменные:
- `BOT_TOKEN`: токен из [@BotFather](https://t.me/BotFather)
- `ADMIN_CHAT_ID`: ID группы администраторов
- `DEEPSEEK_API_KEY`: ключ с [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys)

### 2. Локальный запуск на Windows:
Дважды кликните по **`run.bat`** или выполните в терминале:
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

### 3. Деплой на Railway:
1. Загрузите репозиторий на GitHub.
2. В панели Railway выберите **New Project -> Deploy from GitHub repo**.
3. Добавьте переменные окружения (`BOT_TOKEN`, `ADMIN_CHAT_ID`, `DEEPSEEK_API_KEY`, `DEEPSEEK_BASE_URL`, `DEEPSEEK_MODEL`, `TIMEZONE=Asia/Tashkent`).
4. Railway автоматически соберет проект по `Dockerfile` / `Procfile` и запустит воркер 24/7.
