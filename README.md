# 🦷 DentaLux Tashkent — Премиальный B2B AI-Ассистент для Стоматологии

Интеллектуальный Telegram-бот на базе **Python 3.11+**, **aiogram 3.x** и **DeepSeek API (`deepseek-chat`) / OpenAI API (`gpt-4o` / `gpt-4o-mini`)** с поддержкой **Function Calling**, разработанный специально для частных стоматологических клиник и центров эстетической медицины в **Ташкенте**.

---

## 🎯 Бизнес-задачи и ценность

- **Высокий чек ниши:** Пациенты на брекеты, элайнеры, виниры и имплантацию приносят клинике от **$500 до $3,000+**.
- **Окупаемость рекламы:** При затратах на таргет в Instagram/Facebook от $1,000 до $4,000 в месяц бот исключает потерю лидов.
- **Работа 24/7 без потерь:** Более **40% заявок** приходят вечером, ночью и в выходные. Бот отвечает за 2-3 секунды, квалифицирует интерес и забирает номер телефона.
- **Двуязычие (UZ/RU):** Безупречное и естественное общение на русском и узбекском языках (латиница и кириллица) с автоматическим распознаванием с первого сообщения.
- **Безопасность:** Защита от медицинских галлюцинаций — бот не ставит диагнозы, а закрывает пациента на **бесплатную консультацию главного врача + 3D-снимок (КТ)**.

## ⚡️ Функционал

### 1. Интеллектуальный диалог и воронка продаж
- **Автоопределение языка:** Мгновенно подстраивается под язык пациента (`Assalomu alaykum`, `Xush kelibsiz` / `Здравствуйте`).
- **База знаний по Ташкенту:**
  - Клиника **"DentaLux Tashkent"**, Мирабадский район, метро Ойбек, напротив Grand Mir Hotel.
  - Услуги и прайсы в сумах и долларах: брекеты Damon Q2, элайнеры Spark, импланты Osstem и Straumann, виниры E.max, отбеливание Beyond/Zoom, детская стоматология.
  - Рассрочка 0% через Uzum Nasiya, Anorbank, Zoodpay.
  - Стерилизация инструментов по стандартам «Анти-СПИД / Анти-Гепатит» (немецкие автоклавы Melag, крафт-пакеты вскрываются при пациенте).
- **Квалификация:** Мягко выясняет жалобу/пожелания, рассказывает о преимуществах и берет контакт: имя, телефон (+998), удобное время.

### 2. Модуль отправки лида
Как только получен номер телефона, бот через **Function Calling** (`register_lead`):
1. Сохраняет лид в базу SQLite.
2. Мгновенно отправляет форматированную карточку в чат руководства/администраторов:
   ```text
   🔥 НОВАЯ ЗАЯВКА С ТЕЛЕГРАМ-БОТА!

   🆔 Заявка №: #12
   👤 Имя: Алишер
   📞 Телефон: +998 90 123 45 67
   🦷 Услуга: Консультация по брекетам Damon
   📅 Удобное время: Завтра после 15:00
   💬 Краткая суть диалога: Беспокоит прикус, хочет металлические брекеты, спрашивал про рассрочку 0%.
   🌐 Язык: Узбекский (O'zbek)
   ⏰ Время заявки: 21:45 (03.11.2026) (Ташкент)
   📱 Telegram: @alisher_uz (ID: 123456789)
   ```
3. Добавляет строку в Google Таблицу клиники.
4. Отправляет пациенту персонализированное подтверждение.

### 3. Перевод на живого администратора
- Если пациент нажимает кнопку **«👨‍💼 Связаться с администратором»** или пишет *"позовите человека"* / *"admin bilan gaplashmoqchiman"*:
  - Бот переключает пользователя в режим `is_operator_mode`.
  - В админ-чат отправляется алерт с прямой ссылкой на чат с пациентом.
  - Сообщения пациента передаются администратору без вмешательства AI.
  - Администратор или пациент могут вернуть AI в любой момент кнопкой или командой `/bot`.

### 4. Нативная кнопка «📱 Отправить мой телефон»
- В Узбекистане подавляющее большинство пользователей сидит в Telegram со смартфонов. Одно нажатие на кнопку отправляет подтвержденный номер телефона прямо в карточку заявки.

## 🚀 Настройка и запуск

### 1. Настройка `.env`
В файле `.env` уже сохранены ваши `BOT_TOKEN` и `ADMIN_CHAT_ID`.
Осталось только указать ключ DeepSeek:
```env
DEEPSEEK_API_KEY=sk-ваш_ключ_deepseek
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```
*(Получить ключ можно на [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys)).*

### 2. Запуск в 1 клик
Дважды кликните по файлу **`run.bat`** в папке проекта.
Бот подключится к Telegram и начнет принимать заявки!
